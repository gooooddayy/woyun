# 我晕 (WoYun) — 防晕车出行助手

> 一款纯本地、无广告、不联网的晕动症缓解小工具：屏幕常驻视觉锚点 + 100HZ低频舒缓音，坐车坐船坐飞机也能安心刷手机。

## 定位

**「我晕」是一款用「屏幕视觉锚点 + 100低频音」帮你缓解晕车、晕船、晕机的本地小工具——不联网、无广告，坐车也能照常玩手机。**

---

## 工作原理

晕动症（晕车 / 晕船 / 晕机）的本质是**感官冲突**：内耳前庭感知到身体在晃动，而眼睛看到车内、舱内相对静止的景物，大脑同时收到"在动"和"没动"的矛盾信号，于是产生眩晕、恶心。

「我晕」从两个角度削弱这种冲突：

1. **视觉锚点法（核心）**  
   在屏幕最上层常驻一个**固定的视觉参考点**（柔光圆点）。当眼睛有了一个稳定、不随车身晃动的视觉基准，前庭与视觉信号的不一致被弱化，大脑对"运动"的误判下降，眩晕感随之减轻。圆点可调节大小、透明度与位置，不遮挡你要看的内容。
2. **低频音辅助**  
   叠加一段约 **100Hz 的低频纯音**循环播放，作为舒缓的背景声，帮助放松神经、进一步平复恶心感。音量可调，并带淡入淡出，不会"啪"地一下突然出声。

两者可独立开关、自由组合，按你的体感选择只用圆点、只听音，或两者一起。

## 功能介绍

- **视觉圆点（悬浮窗）**  
  常驻屏幕的柔光圆点；以系统悬浮窗形式叠加在所有应用之上，导航、刷视频、回消息都不耽误。
- **100低频音**  
  约 100Hz 纯音循环播放，音量可调，带淡入淡出；可单独开启，作为"安静背景音"使用。
- **自由组合**  
  圆点与低频音各自独立开关，可只用其一，也可同时开启，适配不同人群、不同路况的体感。
- **极简控制**  
  主界面一键开关，状态一目了然；首次使用引导授予悬浮窗权限，无多余设置。

## 使用建议

1. 上车 / 登船 / 登机**前**就开启，比已经晕了再开效果更好。
2. 圆点放在视野余光处（如屏幕角落），既能做视觉锚点又不太挡内容。
3. 低频音从低音量起步，慢慢调到自己舒服的程度。
4. 仍感不适时，配合闭眼休息、看远处、通风，效果更佳。

## 安装

产物：`我晕.apk`（已签名，可直接安装）

1. 把 APK 传到手机（数据线 / 微信文件传输助手 / 云盘均可）
2. 点击安装，允许"安装未知来源应用"
3. 或用 adb：`adb install -r 我晕.apk`

首次使用需要授予两个权限：

| 权限 | 用途 | 授予方式 |
|---|---|---|
| 显示在其他应用上层（悬浮窗） | 圆点要画在所有 App 和桌面之上 | 点「开始」后会自动跳转系统设置 |
| 通知权限（Android 13+） | 通知栏常驻开关 | 首次启动时弹窗询问 |

> 小米 / 华为 / OPPO / vivo 等国产 ROM：如果开启后回到桌面圆点消失，请在「设置 → 应用 → 我晕」里额外允许**后台弹出界面**、**自启动**，并把应用加入电池优化白名单。

## 使用

- 主界面点「开始」→ 圆点出现在所有界面之上
- 通知栏常驻一条通知，带「暂停 / 继续」和「关闭」按钮
- 回到 App 点「关闭」，或点通知栏的「关闭」，圆点和通知一起消失
- 「提示强度」滑块可实时调整圆点位移幅度（50%–250%）
- 车辆静止一段时间后圆点自动变淡，重新移动后恢复；息屏时自动停用传感器省电

## 技术实现

```
加速度计 + 陀螺仪 (+重力传感器)
        ↓  互补滤波估计重力方向（陀螺预测 + 加速度慢修正，持续加速时不污染重力估计）
        ↓  线性加速度 = 原始加速度 − 重力
        ↓  由屏幕朝向推算车辆前向轴：normalize(horiz(−Z轴) + horiz(屏幕上方向))
        ↓  投影得到 纵向 / 横向 / 垂向 分量 + 绕竖直轴的偏航角速度
        ↓  二级低通(≈1.1Hz) + 长时漂移消除(18s) + tanh 软饱和
        ↓  每个圆点独立的二阶弹簧阻尼积分（刚度错开，形成柔和的流体跟随）
        ↓  Choreographer 帧同步绘制，静止时挂起循环
```

关键点：**手机姿态是任意的**。竖着拿时车辆的前后加速度几乎垂直于屏幕，如果直接用设备坐标系，屏幕上根本看不出加减速。所以必须先把加速度换算到车辆坐标系，再固定映射为「前后 → 屏幕上下」「左右 → 屏幕左右」。

| 文件 | 职责 |
|---|---|
| `MotionEngine.java` | 传感器采集与运动解算 |
| `CuesView.java` | 圆点布局、弹簧物理、绘制 |
| `OverlayService.java` | 系统级悬浮窗 + 前台服务 + 通知开关 |
| `MainActivity.java` | 主界面、权限引导、实时预览 |
| `Prefs.java` | 配置存储 |

- minSdk 24 (Android 7.0)，targetSdk 36

## 重新构建

方式一（已验证，不需要 Gradle 和网络）：

```bash
bash build.sh
```

直接调用 SDK 工具链 `aapt2 → javac → R8(混淆+dex) → zipalign → apksigner`，产出根目录的 `我晕.apk`。
脚本内的 SDK / JDK 路径已按本机环境写死，换机器需改 `build.sh` 顶部变量。

方式二：用 Android Studio 打开本目录（标准 Gradle 工程结构），首次会联网下载 AGP 和 Gradle。

签名密钥在 `keystore/woyun.jks`（口令 `woyun123`，别名 `woyun`），首次构建自动生成，之后复用，保证升级安装不冲突。
